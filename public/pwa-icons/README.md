# Icônes PWA

Ce dossier doit contenir les icônes pour l'installation de la PWA.

**Tailles requises :**
- `icon-192x192.png` - Icône principale (192x192px)
- `icon-512x512.png` - Icône haute résolution (512x512px)

**Pour créer les icônes PNG :**

Depuis le dossier `public/pwa-icons`, vous pouvez utiliser :
- Un outil en ligne : https://realfavicongenerator.net/
- ImageMagick : `convert icon.svg -resize 192x192 icon-192x192.png`
- Figma, Photoshop, ou autre outil de design

**Pour l'instant :**
Le fichier `icon.svg` est fourni comme template. Convertissez-le en PNG pour activer l'installation PWA.
